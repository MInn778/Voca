# talk — 일상 회화 문장 만들기 (단어 배열)

## 맡은 업무

일상 상황(카페, 공항, 전화 등)의 회화 문장을 섞인 단어로 직접 조합하게 해, 실제로 입에서 나오는 표현을 연습시킨다.

## 필요한 입력

- `../../data/talk.md` — 상황별 상태(미시작/진행중/복습필요/완료), 최근 정답률, 오답 메모
- `../../data/words.md` — 학습한 토익 단어 (자연스러우면 문장에 섞어 쓴다)

## 행동 순서

1. `data/talk.md`를 읽는다.
2. 상황을 제안한다: ① "복습필요" → ② "진행중" → ③ "미시작" 중 코드가 가장 빠른 것. 사용자가 다른 상황을 원하면 따른다.
3. 그 상황에서 실제로 쓰는 회화 문장 5개로 **단어 배열 문제**를 낸다. 문제마다:
   - 한국어 해석을 준다.
   - 영어 문장을 단어 단위로 쪼개 **순서를 섞어** ` / `로 구분해 보여준다. 모두 소문자로 쓰고 문장부호(?, ., ,)는 빼서 첫 단어나 끝 단어가 티 나지 않게 한다. 단, 고유명사와 `I`는 대문자 그대로 둔다.
   - 예: `카페 직원: 무엇을 드릴까요?` → `get / you / what / I / for / can`  (정답: What can I get for you?)
   - 문장 길이는 5~9단어. 앞뒤 대화 한 줄을 영어로 함께 보여줘 상황을 알 수 있게 한다.
   - 정답 문장을 먼저 보여주지 않는다.
   - "복습필요"면 오답 메모에 있는 문장을 다시 포함한다.
4. 사용자가 조합한 문장을 채점한다. 대소문자·문장부호는 따지지 않는다. 주어진 단어를 모두 한 번씩 썼고 문법적으로 맞으면서 원어민이 실제로 쓰는 순서면, 정답과 순서가 달라도 정답으로 인정한다. 단어를 빼먹거나 순서가 틀리면 오답이고, 올바른 문장과 어디가 틀렸는지(예: 조동사-주어 도치)를 설명한다.
5. 정답률 = 정답 수 / 5.
   - 80% 이상 → "완료"
   - 80% 미만 → "복습필요", 틀린 표현을 오답 메모에 남긴다
6. `data/talk.md`의 해당 행(상태, 정답률, 오답 메모, 마지막 학습일)을 갱신한다.
7. `data/log.md`에 한 줄 append한다: 날짜, 유형(talk), 상황, 문제 수, 정답 수, 정답률, 틀린 표현.

## 완료 기준

`data/talk.md`와 `data/log.md`가 모두 이번 세션 결과로 갱신되어 있어야 완료다.
