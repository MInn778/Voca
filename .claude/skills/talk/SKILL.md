# talk — 일상 회화 문장 완성

## 맡은 업무

일상 상황(카페, 공항, 전화 등)의 짧은 대화문에서 빈칸을 채우게 해, 실제로 입에서 나오는 표현을 연습시킨다.

## 필요한 입력

- `../../data/talk.md` — 상황별 상태(미시작/진행중/복습필요/완료), 최근 정답률, 오답 메모
- `../../data/words.md` — 학습한 토익 단어 (자연스러우면 문장에 섞어 쓴다)

## 행동 순서

1. `data/talk.md`를 읽는다.
2. 상황을 제안한다: ① "복습필요" → ② "진행중" → ③ "미시작" 중 코드가 가장 빠른 것. 사용자가 다른 상황을 원하면 따른다.
3. 그 상황의 짧은 대화문(2~4줄) 5개를 낸다. 각 대화문에서 핵심 표현 하나를 빈칸 `_____`으로 비우고, 옆에 한국어 뜻 힌트를 준다. 정답을 먼저 보여주지 않는다.
   - 예: A: Can I get a latte? B: Sure. For here or _____? (가져가실 건가요?)
   - "복습필요"면 오답 메모에 있는 표현을 다시 포함한다.
4. 사용자가 답하면 채점한다. 정답과 다르더라도 원어민이 실제로 쓰는 자연스러운 표현이면 정답으로 인정하고, 더 자연스러운 표현이 있으면 함께 알려준다. 문법은 맞지만 어색한 표현은 "부분 정답"(오답으로 계산).
5. 정답률 = 정답 수 / 5.
   - 80% 이상 → "완료"
   - 80% 미만 → "복습필요", 틀린 표현을 오답 메모에 남긴다
6. `data/talk.md`의 해당 행(상태, 정답률, 오답 메모, 마지막 학습일)을 갱신한다.
7. `data/log.md`에 한 줄 append한다: 날짜, 유형(talk), 상황, 문제 수, 정답 수, 정답률, 틀린 표현.

## 완료 기준

`data/talk.md`와 `data/log.md`가 모두 이번 세션 결과로 갱신되어 있어야 완료다.
