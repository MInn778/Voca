# study — 오늘 외울 단어 정하고 설명

## 맡은 업무

오늘 학습할 단어 묶음을 정하고, 뜻·예문·헷갈리는 포인트를 설명한다. 퀴즈·채점은 `/test`가 한다.

## 필요한 입력

- `../../data/words.md` — Day별 단어와 단어별 상태(새단어/학습중/복습필요/암기완료), 틀린 횟수, 마지막 학습일. 맨 위에 `다음에 가져올 pool 번호`가 있다.
- `../../data/pool.md` — 토익 독종반 「토익 단어 모음」 PDF에서 추출한 빈출 순 단어 2,109개 (번호, 단어, 뜻). 새 Day를 만들 때만 필요한 번호 부근만 읽는다 (파일이 크므로 전체를 읽지 않는다).

## 행동 순서

1. `data/words.md`를 읽는다.
2. 오늘 학습할 단어를 제안한다:
   - "복습필요" 단어가 있으면 먼저 보여준다 (틀린 횟수가 많은 순).
   - 그다음 "새단어"가 남아 있는 Day 중 가장 빠른 Day의 단어 전체.
   - 모든 Day에 "새단어"가 없으면 `data/pool.md`에서 다음 Day를 만든다:
     - `다음에 가져올 pool 번호`부터 순서대로, `words.md`에 이미 있는 단어는 건너뛰고 20개를 고른다.
     - `## Day N — pool #시작~#끝` 제목으로 `words.md` 맨 아래에 같은 표 형식으로 추가한다. 품사는 pool의 (명)/(동)/(형)/(부)/(전)을 n/v/a/ad/prep로 바꾸고, 뜻은 pool의 뜻을 그대로 옮긴다(여러 뜻이면 `/`로 구분). 예문은 pool에 없으므로 그 단어의 토익식 쓰임을 보여주는 짧은 비즈니스 예문을 새로 쓴다. 상태는 "새단어".
     - `다음에 가져올 pool 번호`를 마지막으로 확인한 번호 + 1로 갱신한다.
   - 후보와 이유(예: "복습필요 3개 + Day 2 새단어 20개 어때요?")를 보여주고 확인받는다.
3. 단어마다 뜻, 품사, 예문을 설명한다. 토익에서 자주 나오는 짝꿍 표현(collocation)이나 헷갈리는 단어(예: affect/effect)가 있으면 함께 짚어준다. "복습필요" 단어는 지난번에 왜 틀렸을지 한 줄로 짚어준다.
4. 설명한 단어 중 "새단어"는 "학습중"으로 바꾸고, 설명한 모든 단어의 마지막 학습일을 오늘로 갱신한다.
5. 설명을 마치면 "다 봤으면 `/test`로 퀴즈 풀어볼까요?"라고 안내한다.

## 완료 기준

`data/words.md`의 상태·학습일이 갱신되어 있어야 완료다.
