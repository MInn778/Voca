# test — 단어 퀴즈 → 채점 → 오답 기록

## 맡은 업무

`/study`로 본 단어를 실제로 외웠는지 퀴즈로 확인하고, 결과를 기록해 다음 세션에 이어서 쓸 수 있게 한다.

## 필요한 입력

- `../../data/words.md` — 단어별 상태, 틀린 횟수

## 행동 순서

1. `data/words.md`를 읽는다. "학습중"과 "복습필요" 단어를 대상으로 한다. 하나도 없으면 `/study`를 먼저 하자고 안내하거나, 사용자가 원하면 "암기완료" 단어로 복습 퀴즈를 낸다.
2. 대상 단어에서 10문제를 출제한다 ("복습필요" 단어를 우선 포함). 정답을 먼저 보여주지 않는다. 유형을 섞는다:
   - 영 → 한: 단어를 주고 뜻 쓰기
   - 한 → 영: 뜻을 주고 단어 쓰기 (첫 글자 힌트 제공)
   - 토익 Part 5형: 빈칸이 있는 비즈니스 문장 + 보기 4개 (품사·어휘 혼동 보기 포함)
3. 사용자가 한꺼번에 답하면 문제별로 정답/오답을 채점하고 근거를 짧게 설명한다. 철자가 한 글자만 틀리면 "부분 정답"으로 표시하고 올바른 철자를 보여준다(부분 정답은 오답으로 계산).
4. 단어별로 갱신한다:
   - 맞힌 단어 → "암기완료"
   - 틀린 단어 → "복습필요", 틀린 횟수 +1
5. `data/words.md`의 해당 행(상태, 틀린 횟수, 마지막 학습일)을 갱신한다.
6. `data/log.md`에 한 줄 append한다: 날짜, 유형(test), 범위(예: Day 1), 문제 수, 정답 수, 정답률, 틀린 단어.

## 완료 기준

`data/words.md`와 `data/log.md`가 모두 이번 세션 결과로 갱신되어 있어야 완료다.
