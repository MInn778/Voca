# test — 단어 퀴즈 → 채점 → 오답 기록

## 맡은 업무

`/study`로 본 단어를 실제로 외웠는지 퀴즈로 확인하고, 결과를 기록해 다음 세션에 이어서 쓸 수 있게 한다.

## 필요한 입력

- `../../data/words.md` — 단어별 상태, 틀린 횟수

## 행동 순서

1. `data/words.md`를 읽는다. 대상은 다음 두 그룹을 합친 것이다:
   - 오늘 `/study`에서 새로 다룬 Day의 단어 전체(보통 20개, 상태 "학습중").
   - 상태가 "복습필요"인 단어 전체(다른 Day 것 포함 — 어제 이전 시험에서 틀려서 아직 못 맞힌 단어들이라, 맞힐 때까지 매일 시험에 자동으로 이어서 나온다).
   - 대상이 하나도 없으면 `/study`를 먼저 하자고 안내한다.
2. 5일마다는 이 기본 대상 대신 전체 시험을 낸다: 오늘 다룬 Day 번호가 5의 배수(Day 5, 10, 15 ...)이면, 최근 5개 Day(예: Day 1~5) 단어 전체(약 100개, 상태 무관)를 대상으로 한다. 여기서 틀린 단어는 평소처럼 "복습필요"로 표시되어 Day 6 시험부터 자동으로 이어진다.
3. 대상 단어 전체를 랜덤 순서로 출제한다 (개수를 줄이지 않는다). 유형은 영 → 한(단어를 주고 뜻 쓰기) 하나만 쓴다. 정답을 먼저 보여주지 않는다.
4. 사용자가 한꺼번에 답하면 문제별로 정답/오답을 채점하고 근거를 짧게 설명한다. 철자가 한 글자만 틀리면 "부분 정답"으로 표시하고 올바른 철자를 보여준다(부분 정답은 오답으로 계산).
5. 단어별로 갱신한다:
   - 맞힌 단어 → "암기완료"
   - 틀린 단어 → "복습필요", 틀린 횟수 +1
6. `data/words.md`의 해당 행(상태, 틀린 횟수, 마지막 학습일)을 갱신한다.
7. `data/log.md`에 한 줄 append한다: 날짜, 유형(test), 범위(예: "Day 3 + 복습 2개", 5일 전체 시험이면 "Day 1~5 전체"), 문제 수, 정답 수, 정답률, 틀린 단어.

## 완료 기준

`data/words.md`와 `data/log.md`가 모두 이번 세션 결과로 갱신되어 있어야 완료다.
