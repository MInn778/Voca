# Voca — 토익 단어장 자비스

Claude Code로 동작하는 **토익 단어 학습 시스템**입니다. 단어를 외우고(`/study`), 퀴즈로 확인하고(`/test`), 일상 회화 문장을 연습합니다(`/talk`). 결과는 파일에 기록되고, 다음에 공부할 때 그 기록에서 이어서 시작합니다.

## 왜 필요한가

단어장 앱이나 종이 단어장으로 공부할 때 반복되는 문제가 있습니다.

- **어디까지 외웠는지 모른다.** 어제 본 단어 중 어떤 걸 외웠고 어떤 걸 못 외웠는지 기억에 의존하게 됩니다.
- **틀린 단어가 다시 안 나온다.** 한 번 틀린 단어도 목록 순서대로 넘어가면 다시 볼 기회가 없습니다.
- **뜻만 외우고 시험에서는 못 푼다.** 토익 Part 5는 뜻보다 품사(applicant/application), 전치사 쓰임(attend vs attend to), 비슷한 단어 구분(efficient vs effective)을 묻습니다.
- **단어만 알고 입으로는 못 쓴다.** 외운 단어와 표현을 실제 대화에서 써 볼 기회가 없습니다.

Voca는 단어마다 상태(새단어/학습중/복습필요/암기완료)와 틀린 횟수를 파일로 남깁니다. 그래서 틀린 단어부터 다시 공부하게 하고, 토익 실전 유형으로 문제를 내고, 회화 빈칸 완성으로 표현을 연습시킵니다.

## 기능

### `/study` — 오늘 외울 단어 학습
- 복습필요 단어(틀린 횟수가 많은 순)를 먼저, 그다음 아직 안 본 Day의 단어 20개를 제안합니다.
- 단어마다 뜻, 품사, 예문과 함께 **토익에서 짝으로 나오는 표현**(`meet the deadline`, `implement a policy`)과 **헷갈리는 단어**(employee/employer)를 짚어 줍니다.
- 준비된 Day를 다 외우면 목록에 없는 토익 빈출 단어로 새 Day를 만들어 추가합니다.
- **왜**: 매번 처음부터 보지 않고, 약한 단어에 시간을 쓰기 위해서입니다.

### `/test` — 단어 퀴즈와 채점
- 10문제를 세 가지 유형으로 섞어 냅니다: 영→한 뜻 쓰기, 한→영 단어 쓰기(첫 글자 힌트), 토익 Part 5형 4지선다.
- 맞힌 단어는 "암기완료", 틀린 단어는 "복습필요"로 바꾸고 틀린 횟수를 늘립니다.
- 문제를 모르면 해석과 보기별 풀이까지 설명합니다.
- **왜**: 외웠다고 느끼는 것과 실제로 푸는 것은 다르기 때문입니다. 틀린 단어는 다음 `/study`에 다시 나옵니다.

### `/talk` — 일상 회화 문장 완성
- 카페, 공항·호텔, 전화, 동료와 스몰토크 등 10가지 상황의 짧은 대화문에서 빈칸을 채웁니다.
- 정답과 달라도 원어민이 실제로 쓰는 표현이면 정답으로 인정하고, 더 자연스러운 표현을 알려 줍니다.
- **왜**: 단어를 아는 것에서 끝나지 않고 문장으로 말할 수 있게 하기 위해서입니다.

## 사용 방법

1. 이 레포를 받아 폴더를 Claude Code로 엽니다.
2. `/study`로 오늘 단어를 봅니다.
3. `/test`로 퀴즈를 풉니다.
4. 회화 연습은 `/talk`입니다.

학습 결과는 `data/` 폴더에 자동으로 기록됩니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `CLAUDE.md` | 비서의 규칙: 매번 진도 파일을 먼저 읽기, 정답을 먼저 알려주지 않기, 채점 후 반드시 기록하기 |
| `.claude/skills/study/SKILL.md` | `/study` 동작 정의 |
| `.claude/skills/test/SKILL.md` | `/test` 동작 정의 |
| `.claude/skills/talk/SKILL.md` | `/talk` 동작 정의 |
| `data/words.md` | Day별 단어와 단어별 상태·틀린 횟수 |
| `data/talk.md` | 회화 상황별 진도·정답률·오답 메모 |
| `data/log.md` | 학습 기록 (날짜, 범위, 정답률, 틀린 단어) |

## 참고

- 기본 단어 60개(Day 1~3)와 뜻·예문은 특정 교재나 기출 자료에서 가져온 것이 아니라 Claude가 작성했습니다. 쓰고 있는 교재가 있으면 `data/words.md`를 같은 형식으로 바꿔 쓰면 됩니다.
- 회화 대화문은 파일에 저장하지 않고 `/talk`를 실행할 때마다 새로 만듭니다.
